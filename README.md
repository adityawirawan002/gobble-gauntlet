**Gobble Gauntlet** is an original HTML5 Canvas action-stealth turkey escape game built offline with zero external dependencies and procedural Web Audio synthesis. Play as Barnaby the Turkey sprinting, flutter-gliding, feather-dashing, hiding in stealth cover, and tossing acorn decoys across three escalating autumn stages — **Golden Farmyard**, **Smokehouse Cellar**, and the **Thanksgiving Kitchen Gauntlet** — while evading the pursuing Farmer/Chef, roaring roasting ovens, and spinning carving knives on your dash toward the open escape window.

### Controls
- **Move**: `WASD` or `Arrow Keys`
- **Flutter Jump & Glide**: `Space` / `W` / `Up` / `Left-Click` (hold in air to flutter-glide)
- **Feather Dash**: `Shift` / `K` / `Right-Click` (burst speed + brief i-frames + Close Shave bonus)
- **Stealth Hide**: `E` / `S` / `Down` inside Hay Bales, Pumpkin Crates, or Copper Pots
- **Toss Acorn Decoy**: `Q` (lures the Farmer's lantern cone away)
- **Pause / Restart / Audio**: `P` or `Esc` · `R` · `M`

## Run it

```bash
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser.
