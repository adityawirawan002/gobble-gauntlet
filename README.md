**Gobble Gauntlet** is an original HTML5 Canvas multi-tier action-stealth turkey escape game built 100% offline with zero external dependencies and procedural Web Audio synthesis. Play as **Barnaby the Turkey** vaulting barn rafters, riding chimney and stockpot steam updrafts, feather-dashing for Close Shave bonuses, hiding inside hay bales, cider barrels, and copper pots, and tossing acorn decoys across three escalating autumn stages — **Golden Farmyard**, **Smokehouse & Orchard**, and the **Thanksgiving Kitchen Gauntlet** — while outwitting **Farmer / Chef Jed's** volumetric lantern searchlight, catcher nets, carving knives, Buster the Farm Dog, and roaring roasting ovens on your dash to the moonlit open escape window.

### Controls
- **Move**: `WASD` or `Arrow Keys`
- **Jump & Flutter-Glide**: `Space` / `W` / `Up` / `Left-Click` (hold in air to flutter-glide or ride steam updrafts)
- **Feather Dash**: `Shift` / `K` / `Right-Click` (speed burst + brief i-frames + Close Shave stamina refund)
- **Stealth Hide / Drop-Through**: `E` / `S` / `Down` inside Hay Bales, Cider Barrels, or Copper Pots (or drop through rafters)
- **Toss Acorn Decoy**: `Q` / `F` (bounces and rings to lure Farmer Jed & Buster away)
- **Stage Select / Pause / Restart / Audio**: `1-3` on Title · `P` or `Esc` · `R` · `M`

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser.
